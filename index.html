        How to use

        Drag furniture · double click or R = turn 90° · Q/E = ±15° · drag the round handle = turn freely · arrow keys = 1 cm (Shift 10 cm) · Shift while dragging = no snapping · Ctrl+click = group with the selected piece · D = duplicate · Del = set aside · Ctrl+Z/Y = undo/redo · Esc = deselect · drag the background = pan, mouse wheel = zoom. Every key has a button in the Selected panel, and the Schedule selects a piece without the mouse.

        Furniture set aside waits in the parking area next to the room and is not checked. A cross and a solid red frame = runs into something, an exclamation mark and a dashed orange frame = blocks a door.
